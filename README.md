OnepersonAI‑website is a private React 19 single‑page app scaffolded with Create‑React‑App, offering standard scripts (`start`, `build`, `test`, `eject`) and a minimal UI layout under `src/` and static assets in `public/`. The repository includes basic testing utilities, a `docs/ARCHITECTURE.md` for design notes, and a permissive LICENSE for open‑source use.
